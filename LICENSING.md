# Licenciamiento de ChatLog

Este repositorio contiene dos tipos de componentes con licencias distintas.

## Código fuente (extensión de Chrome)

El código fuente de la extensión se distribuye bajo la **Apache License 2.0**.

Esto incluye todos los archivos `.js`, `.html`, `.css`, `.json` y demás archivos
de código que conforman la extensión ChatLog.
